# `= this.file.aliases[0]`
> `= this.description`.

Eating recovers one [[stat_stamina|Stamina]] per [[item_ration|Ration of Food]]. You can consume any number of rations in a single meal.

Eating to recover [[stat_stamina|Stamina]] doesn't count towards avoiding the [[cond_starvation|Starvation Condition]]. For that, an additional [[item_ration|Food Ration]] must be consumed.
