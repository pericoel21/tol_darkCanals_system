On [[mechanic_watches|Daybreak]], any weapon used the previous 24h becomes [[traits_rusty|Rusty]] if it was not oiled.

## Performing Maintenance
- Takes a few minutes.
- Uses one portion of [[item_oilFlask|Oil]].

## Repairing Rust
- Takes a few minutes.
- Uses one portion of [[item_oilFlask|Oil]].
- Needs a [[item_whetstone|Whetstone]].
