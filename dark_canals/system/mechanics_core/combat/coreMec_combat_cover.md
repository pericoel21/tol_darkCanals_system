## Shooting & Cover

|                            | Impenetrable Cover                                                                                                                    | Penetrable Cover                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Target completely obscured | Target `In Cover`, not possible to be hit.                                                                                            | Target `In Cover`but possible to hit by rolling `HARDER`. |
| Target partially obscured  | Target `Out of Cover`, can be attacked. If rolled [[combat_hitLocations\|Hit Location]] is behind cover, it counts as a miss. | Target `Out of Cover`as if no Cover.                      |

### In vs. Out of Cover
If there's cover around, characters have to declare if they are `In Cover` or `Out of Cover`.
- If a character is `In Cover`, they cannot [[combat_ranged|Shoot]].
- If a character is `Out of Cover`, they can [[combat_ranged|Shoot]].

### Penetrable vs. Impenetrable
- GM judgement.
- Penetrable = thinner than wooden planks.
