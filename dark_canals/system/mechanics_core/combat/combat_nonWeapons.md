# `= this.file.aliases[0]`
> `= this.description`.

- A character cannot be [[mechanic_profficiencies|Proficient]] in fighting with things that weren’t designed to be weapons
- Improveised Weapons don't have [[mechanic_itemTraits|Weapon Traits]].
- [[mechanic_itemTraits|Other Traits]] still work as usual.
- A [[trait_heavy|Heavy]] (two-handed) improvised weapon, causes [[mechanic_injury|Severe Injury]].

## Wood Head Arrows
- [[mechanic_crafting|Crafted]] from [[item_woodScrap|Wood Scrap]].
- Count as Improvised Weapons, do only [[mechanic_injury|Severe Injuries]].
