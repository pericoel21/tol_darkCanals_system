## Previous knowledge
If a PC knows about a thing, the GM will include that knowledge in their initial description of the thing.

## Research
A character can look for information about a topic as long as they are in a library or have the relevant documentation, book, etc.

### Research Check
- Roll [[skill_reason|REASON]].
- [[mechanic_difficulty|Difficulty]] depends on the rarity of the topic.

| Context                         | Duration                        | Is roll repeatable after a failure? |
| ------------------------------- | ------------------------------- | ----------------------------------- |
| Looking for info in a book      | One minute                      | No, info is not there.              |
| Lookinf for a book in a library | One [[mechanic_watches\|Watch]] | Yes, after a day.                   |

## Buying Books
- Only `CONTEMPORARY` rarity and lower are for sale.
- They all cost 1 [[mechanic_coin|COIN]]
- You can also buy a [[item_bookshelf|bookshelf]] for 1 coin. It holds 40 [[item_book|books]].

## Topic Rarity, Research Difficulty & Availability

| Rarity         | Difficulty  | Availability              | Translation time |
| -------------- | ----------- | ------------------------- | ---------------- |
| `ESOTERIC`     | `VERY HARD` | Not for sell              |                  |
| `RARE`         | `HARD`      | Not for sell              |                  |
| `CONTEMPORARY` | `AVERAGE`   | 1 [[mechanic_coin\|COIN]] |                  |
| `COMMON`       | `EASY`      | 1 [[mechanic_coin\|COIN]] |                  |
| `UBIQUITOUS`   | `VERY EASY` | 1 [[mechanic_coin\|COIN]] |                  |
